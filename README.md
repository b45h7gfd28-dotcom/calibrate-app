# CALIBRATE

정답과 확신도를 함께 기록하고 나의 학습 패턴을 살펴보는 웹앱입니다.

## 시연 기능

- 객관식 문제 풀이와 답안 선택
- 정답 확인 전 확신도 0~100% 입력
- 정오와 확신도를 조합한 네 가지 유형 확인
- 정답률, 평균 확신도, 유형별 문항 수 리포트
- 높은 확신의 오답을 우선 복습할 문제로 표시

확신도 **0~49%는 낮은 확신**, **50~100%는 높은 확신**으로 분류합니다. 현재 문제 8개는 기능 시연용 예시입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 계정이 필요하지 않습니다. 풀이 기록은 사용 중인 브라우저에 저장됩니다.
